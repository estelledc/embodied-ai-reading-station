# 实践日志

这里只放**你自己真实运行过**的记录：一次跑通、一次报错、一个自己测出来的数、一段用自己的话写的解释。

规则很简单：

- **只写发生过的事。** 没跑通就写"没跑通"，把最后的报错贴上。失败的记录和成功的一样有价值。
- **写清楚环境和命令。** 别人（包括一个月后的你）照着能重来一遍。
- **分清谁做的。** 你自己跑的写"我"；照抄 AI 给的命令也要写明，并说清楚你读懂了哪一步、哪一步还没懂。
- **一次一篇。** 文件名用日期开头，比如 `2026-10-03-stage1-patchify.md`。

新建记录时，复制 [`TEMPLATE.md`](TEMPLATE.md) 改名后填写。

阶段 3 录的示范数据、训练输出和视频很大，不要放进这里，也不要提交到 Git：它们默认在 `lab/stage3_sim/outputs/`，已经被忽略。记录里写上文件放在哪、怎么重新生成就行。
