## 做完以后应该看到

```text
原始图片          (224, 224, 3)
切成小方块        256 块
展平后的矩阵      (256, 588)
每块变成向量      (256, 1024)
投影成 LLM 伪词   (256, 5120)
```

读法：224×224 的图，按边长 14 像素切，横竖各 16 块，一共 256 块；每块有 14×14 个像素、每个像素 3 个颜色值，展平后是 588 个数字；CLIP ViT-L/14 把每块变成 1024 维的向量；LLaVA 的投影矩阵 W 再把它变成语言模型词向量的长度（LLaVA-13B 是 5120，7B 是 4096）。

所以，**一张图在 LLaVA 眼里就是 256 个"伪词"**，和你输入的文字 token 排在同一个序列里，一起交给语言模型。

## 可选：用真实的 CLIP 验证

装好 `../requirements-vla.txt` 之后可以运行（第一次会下载约 1.7 GB 权重）：

```bash
python inspect_clip.py                     # 用程序生成的测试图
python inspect_clip.py --image 你的照片.jpg  # 用自己的照片（需要 pip install pillow）
```

2026-09-27 在本仓库的云端 CPU 环境里实际运行过一次，输出的形状是：

```text
送进 CLIP 的像素      (1, 3, 224, 224)
CLIP 最后一层输出     (1, 257, 1024)   ← 1 个 CLS 向量 + 256 个 patch 向量
LLaVA 取的特征        (1, 256, 1024)   ← 倒数第二层，去掉 CLS
投影后的伪词          (1, 256, 5120)
```

和你用 numpy 算出来的形状一致。多出来的那 1 个是 CLS 向量，LLaVA 把它丢掉了，只用 256 个 patch 向量。
