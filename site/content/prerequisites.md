## 0. 阅读策略：要不要按部就班学完才开始读论文？

**结论先行：不要。**

零基础但擅长用 AI 辅助的读者，**最优策略是「带着问题读，遇到术语回查」**，而不是「学满 6 个月再开读」。原因：

1. 把 6 节全学一遍要 200+ 小时，多数人会在第 30 小时放弃
2. 论文笔记里大部分术语 GPT / Claude 一句话就能给你类比解释
3. 真正卡你的不是「术语不懂」，是「不知道术语之间怎么连」——这只能靠读论文本身练

**推荐节奏**：

| 阶段 | 做什么 | 时长 |
|------|--------|------|
| Day 1-3 | 读完本页，记下不懂的词；打开 1 篇最感兴趣的论文笔记，遇到不懂的词就去本页对应小节查 | 3 天 |
| Week 1-2 | 把第 1、2 节（Python + ML 基础）的视频看完。这两节是真的"不补不行" | 2 周 |
| Week 3+ | 第 3-6 节按需查，不要从头到尾啃 | 长期 |

**例外**：如果你的目标是「自己跑代码复现」而不是「读懂论文在讲什么」，那 Python 必须先学到能写小脚本的程度，再开始读。

## 1. 编程入门：要不要先学 Python？

**要。学到能读懂别人代码 + 写 50 行小脚本就够了。**

读这 13 篇论文不要求你会从零写模型，但**几乎每篇都会贴代码片段**（`model.forward(x)`、`torch.cat(...)`），看不懂代码片段会让阅读体验断断续续。

### 1.1 核心概念（5 个）

| 概念 | 一句话解释 |
|------|------------|
| 变量 / 函数 / 类 | 变量 = 给一个值贴标签；函数 = 一个能反复用的"动作"；类 = 一组数据 + 这组数据能干的事打包成一个对象 |
| 列表 / 字典 / for 循环 | 列表是一排东西按顺序排好；字典是「钥匙→值」的对照表；for 循环是「对每个东西都做一遍同一件事」 |
| import 和包 | 别人写好的代码打成包，`import torch` 就是把 PyTorch 这个工具箱搬进你的工作台 |
| 张量（Tensor） | 升级版的多维列表，能放在 GPU 上算得快——所有论文代码的基本单位 |
| 函数式调用链 | `x = layer1(x); x = layer2(x)` 这种"流水线"风格，深度学习代码 80% 是这种 |

### 1.2 推荐资源

| 资源 | 链接 | 语言 | 时长 | 难度 |
|------|------|------|------|------|
| 廖雪峰 Python 教程 | https://liaoxuefeng.com/books/python/ | 中文 | 边学边查，~10h | 入门 |
| 哈佛 CS50P（Python 版 CS50） | https://cs50.harvard.edu/python/ | 英文（中文字幕） | 视频 ~15h | 入门 |
| 廖雪峰够了再补：Real Python 的 NumPy 入门 | https://realpython.com/numpy-tutorial/ | 英文 | 2-3h | 进阶 |

**学到什么停下**：能看懂下面这段代码并解释每行做什么，就够了。

```python
import torch
x = torch.randn(2, 3)            # 一个 2x3 的随机矩阵
y = torch.nn.Linear(3, 5)(x)     # 过一个 3→5 的线性层
print(y.shape)                   # 输出形状是 [2, 5]
```

### 1.3 解锁哪几篇

学完 Python 基础后，**所有 13 篇论文的代码片段你都能"读个大概"**。重点解锁的是 OpenVLA / LLaVA / Cosmos Policy 这种贴了大量代码示例的笔记。

## 2. 机器学习基础：神经网络在做什么？

**要。这是读懂论文的「公约数」——不会这一节，每篇笔记都会卡住。**

不需要会推导反向传播的公式，只需要建立一个**直觉模型**：神经网络是一个有几百万旋钮的函数，训练就是在拧旋钮让输出靠近答案。

### 2.1 核心概念（5 个）

| 概念 | 一句话解释 + 类比 |
|------|------------------|
| 神经网络（Neural Network） | 一个超长的数学函数 `y = f(x)`，里面有几百万个可调参数。**类比**：调音台，几百个旋钮共同决定声音 |
| 损失（Loss） | 衡量"模型输出"离"正确答案"差多远的一个数。**类比**：考试分数的反面——错得越多 loss 越大 |
| 梯度下降（Gradient Descent） | 每次微调那几百万旋钮，让 loss 变小一点。**类比**：在山上闭着眼下山，每一步往最陡的方向迈一小步 |
| Batch / Epoch | Batch = 每次扔进模型一小批数据（不是一条也不是全部）；Epoch = 整个数据集过完一遍 |
| 过拟合（Overfitting） | 模型把训练题答案背下来了，但换一道新题就崩。**类比**：题海战术只刷原题不练新题 |

### 2.2 推荐资源（按强烈推荐顺序）

| 资源 | 链接 | 语言 | 时长 | 难度 |
|------|------|------|------|------|
| 3Blue1Brown《神经网络》四集系列（必看） | https://www.3blue1brown.com/topics/neural-networks | 英文（中文字幕） | 4 集共 1.5h | 入门——可视化无痛 |
| 吴恩达《机器学习》新版（Coursera + B 站搬运） | https://www.bilibili.com/video/BV1Bq421A74G | 英文（中文字幕） | ~30h | 入门 |
| 李宏毅《机器学习》2024 春 | https://www.bilibili.com/video/BV1JA411c7VT | 中文 | ~40h | 入门——比吴恩达更新 |

**学到什么停下**：3Blue1Brown 四集是"绝对必看"——1.5 小时但收益非常高。后面两个吴恩达 / 李宏毅二选一即可，**不要两个都看**。

### 2.3 解锁哪几篇

| 解锁笔记 | 因为它需要你懂 |
|---------|---------------|
| LLaVA、mmCLIP | 损失函数（contrastive loss）、训练分阶段 |

## 3. 深度学习关键模块：CNN / Transformer / Attention / Embedding / Tokenizer

**要。这一节是读论文的"通用语言"——13 篇里 11 篇都用 Transformer。**

### 3.1 核心概念（5 个，按推荐学习顺序）

| 概念 | 一句话解释 + 类比 |
|------|------------------|
| Embedding | 把"猫"这个词变成一串数字（比如 768 维向量）。**类比**：把每个词放到一个高维"语义地图"上的坐标 |
| Tokenizer | 把句子切成一个个 token（不是字也不是词，介于两者之间）。**类比**：把蛋糕切片，每片是模型的最小输入单位 |
| CNN（卷积神经网络） | 用一个小窗口扫过图像，提取局部特征（边、角、纹理）。**类比**：拿放大镜从左到右扫一张照片 |
| Attention（注意力） | 一个词在理解自己时，"看"句子里其他词的权重。**类比**：读到「它」这个字时，眼睛会瞟回去找前面提到的那个东西 |
| Transformer | 把 Attention 堆很多层，再加上 FFN（前馈层）和残差连接，就是 Transformer。**类比**：流水线工厂，每层工人都看一眼整条流水线再加工自己手里的活 |

### 3.2 推荐学习顺序 + 资源

**强烈建议按这个顺序，跳过任何一步都会卡：**

| 步骤 | 资源 | 链接 | 语言 | 时长 |
|------|------|------|------|------|
| 1. 先看 Embedding 直觉 | 3Blue1Brown《GPT 是什么》第 1 集 | https://www.3blue1brown.com/lessons/gpt | 英 + 中字 | 27min |
| 2. 再看 Attention 直觉 | 3Blue1Brown《Attention》第 6 集 | https://www.3blue1brown.com/lessons/attention | 英 + 中字 | 27min |
| 3. CNN 入门 | 李沐《动手学深度学习》卷积神经网络章 | https://zh.d2l.ai/chapter_convolutional-neural-networks/ | 中文 | 3-4h 阅读 |
| 4. Transformer 完整图解 | Jay Alammar《Illustrated Transformer》（中文翻译版） | https://jalammar.github.io/illustrated-transformer/ | 英 + 中译 | 1h 精读 |
| 5. 跑通一个最小 Transformer（可选） | Karpathy《Let's build GPT from scratch》 | https://www.youtube.com/watch?v=kCc8FmEb1nY | 英文 | 2h 视频 + 4h 复现 |

### 3.3 解锁哪几篇

| 解锁笔记 | 关键概念 |
|---------|---------|
| LLaVA | CLIP 视觉编码器 + LLM 都是 Transformer |
| OpenVLA / VLAS / MLA | Tokenizer 把"动作"也切成 token，VLA 才能用语言模型框架训 |
| 3DShape2VecSet | "把 3D 形状变成向量集合"——是 embedding 思想往 3D 的推广 |
| mmCLIP | CLIP 的 contrastive 思想用在了 mmWave 信号上 |
| Cosmos Policy | 视频生成模型 = 大号 Transformer + 时间维度 |
| SayCan | LLM 那部分就是标准 Transformer |

## 4. 机器人 / 控制理论：SLAM / 感知 / 规划 / 控制

**不必先学。但要建立 4 个名词的"是什么"直觉。**

这部分是论文里"硬科学"含量最高的，但好消息是：13 篇里**只有 3 篇真的需要你懂控制论**（rf-slam / acoustic-swarms / saycan），其他 10 篇用机器人词汇是"借用"，不深入。

### 4.1 核心概念（4 个）

| 概念 | 一句话解释 + 类比 |
|------|------------------|
| 感知（Perception） | 机器人通过摄像头 / 雷达 / 麦克风读取世界。**类比**：人的眼睛 + 耳朵 |
| SLAM（同时定位与建图） | 机器人一边走一边画地图、一边知道自己在地图哪个位置。**类比**：你蒙眼进一个新房间，靠摸墙画出房间形状 |
| 规划（Planning） | 给定起点、终点、地图，找一条路。**类比**：高德导航从家到公司 |
| 控制（Control） | 把"我要往前走 1 米"这条指令翻译成"左轮转 X 圈、右轮转 Y 圈"。**类比**：开车时的油门 + 方向盘 |

### 4.2 推荐资源（按需取用，不必通读）

| 资源 | 链接 | 语言 | 时长 | 难度 |
|------|------|------|------|------|
| 高翔《视觉 SLAM 十四讲》前 3 章（仅扫概念） | https://github.com/gaoxiang12/slambook2 | 中文 | 3-4h 速读 | 入门到中级 |
| 古月居 ROS 入门（建立"机器人有哪些模块"直觉） | https://www.guyuehome.com/ | 中文 | 5h 浏览 | 入门 |
| Stanford CS223A 入门机器人学（仅看 Lec 1-3） | https://cs.stanford.edu/groups/manips/teaching/cs223a/ | 英文 | 4-5h | 中级 |

**学到什么停下**：能用一句话解释 SLAM 是什么、感知和控制的边界在哪——就够了。**不需要会写卡尔曼滤波公式**。

| 解锁笔记 | 用到的概念 |

## 5. 强化学习入门：要不要为 SayCan / OpenVLA 学 RL？

**部分要。建立直觉就够，不需要推公式。**

SayCan 和 OpenVLA 笔记里出现的"价值函数 / 策略 / reward"等词，**90% 可以靠"打游戏类比"理解**，不必啃 Sutton 那本 600 页书。

### 5.1 核心概念（5 个）

| 概念 | 一句话解释 + 类比 |
|------|------------------|
| 智能体 / 环境（Agent / Env） | 智能体 = 玩家；环境 = 游戏。**类比**：你（agent）在玩超级马里奥（env） |
| 状态 / 动作（State / Action） | State = 当前画面 + 角色位置；Action = 你按的键 |
| 奖励（Reward） | 每一步环境反馈给你的分数。**类比**：吃金币 +10、掉坑里 -100 |
| 策略（Policy π） | "看到这个状态我该按哪个键"的规则。**类比**：通关攻略 |
| 价值函数（Value Function V/Q） | "处于这个状态我未来能拿多少分"的估计。**类比**：象棋里"这步棋值不值" |

### 5.2 推荐资源

| 资源 | 链接 | 语言 | 时长 | 难度 |
|------|------|------|------|------|
| 蘑菇书《Easy RL》前 3 章 | https://datawhalechina.github.io/easy-rl/ | 中文 | 3-4h 阅读 | 入门 |
| 李宏毅《强化学习》（B 站搜「李宏毅 RL」） | https://www.bilibili.com/video/BV1XP4y1d7Bk | 中文 | 6h 视频 | 入门 |
| OpenAI Spinning Up（建立 PPO 直觉） | https://spinningup.openai.com/ | 英文 | 5-8h | 中级 |

**学到什么停下**：能解释清楚 reward / policy / value 三个词，看到 "PPO" 知道是某种策略优化算法即可。

### 5.3 解锁哪几篇

| 解锁笔记 | 用到的 RL 概念 |
|---------|--------------|
| SayCan | LLM 给"该做什么"，affordance value 给"能不能做"——本质是 value function |
| OpenVLA | 提到"模仿学习 (Imitation Learning)"，是 RL 的近亲——不靠 reward，靠看专家演示 |
| MLA / Cosmos Policy | 用 imitation learning 训机器人，但不是经典 RL |

## 6. 多模态学习：CLIP 是怎么诞生的？要先读 CLIP 再读 LLaVA 吗？

**强烈推荐先读 CLIP。**

LLaVA 是站在 CLIP 肩膀上的。你不读 CLIP 就读 LLaVA，会一直疑惑"视觉编码器是哪来的、为什么用它"。

### 6.1 核心概念（4 个）

| 概念 | 一句话解释 + 类比 |
|------|------------------|
| 多模态（Multimodal） | 模型能同时处理多种"感官输入"（图、文、音、视频）。**类比**：人能看图说话，不是只能看图或只能听文字 |
| CLIP（对比学习图文对齐） | 把图和它的文字描述放进同一个向量空间，让"匹配的图文"离得近、"不匹配的"离得远 |
| Contrastive Loss（对比损失） | "拉近正例、推远负例"的损失函数。**类比**：磁铁让同极相斥、异极相吸 |
| Visual Instruction Tuning | 在 LLM 上接一个视觉编码器，再用"图 + 问题 + 答案"三元组数据训练。**类比**：给一个会读书的人加上眼睛，再教他看图回答问题 |

### 6.2 推荐学习顺序

| 步骤 | 资源 | 链接 | 语言 | 时长 |
|------|------|------|------|------|
| 1. 先看 CLIP 论文精读（李沐） | B 站搜「李沐 CLIP 精读」 | https://www.bilibili.com/video/BV1SL4y1s7LQ | 中文 | 1h |
| 2. 再读 OpenAI 博客 | https://openai.com/research/clip | 英文 | 30min | |
| 3. 看 LLaVA 论文 + 你站点的 LLaVA 笔记 | https://llava-vl.github.io/ | 英文 | 1.5h | |
| 4. 进阶：CoCa / BLIP / Flamingo（不必全看） | https://arxiv.org/abs/2205.01917 | 英文 | 选读 | |

### 6.3 解锁哪几篇

| 解锁笔记 | 关联 |
|---------|------|
| LLaVA | 直接基于 CLIP-ViT |
| mmCLIP | "把 CLIP 套到 mmWave 信号上"——不懂 CLIP 这篇完全看不懂 |
| OpenVLA / VLAS / MLA | 视觉编码器都是 CLIP 家族 |
| Cosmos Policy | 视觉 backbone 也是 CLIP 系 |

## 附录 C：用 AI 辅助阅读的 3 个高价值 prompt

**零基础读者的杀手锏：让 AI 当陪读。**

```
1. "我在读 [论文名]，遇到一个词 [X]，我已经知道 [Y]。
   请用我懂的 [Y] 来类比解释 [X]，不要超过 100 字。"

2. "把这段论文翻译成「我的本科同学能听懂」的中文，保留所有专业名词
   并在第一次出现时用括号给一句话解释：
   <粘贴英文段落>"

3. "我对 [论文名] 的第 [N] 节有疑问：[贴段落]。
   假设我懂 §3 Transformer 但不懂 §5 RL，
   这段哪些点我应该重点理解、哪些可以跳过？"
```
