# Cosmos Policy: Fine-Tuning Video Models for Visuomotor Control

> 这是机器辅助生成的客观摘要笔记。教学版精读笔记由用户按节奏触发后单独成稿。

## 一句话讲什么（TL;DR）

把一个会"预测下一秒视频"的大模型直接微调成机器人策略，不加任何新模块。

## 这篇论文要解决什么问题（Why this paper）

现实里的麻烦：让机器人学会"折衬衫""把糖放进密封袋"这种活，需要它既懂物理（手抓下去会发生什么）又懂动作的精细多样性。以前主流做法叫 VLA（vision-language-action，视觉-语言-动作模型，比如 OpenVLA、π0），底子是看图配文字训出来的，不太懂"时间一帧一帧怎么演化"。

之前的方法不够在哪里：
- VLA 派的底模型没看过视频，只看过静态图配文字，缺时空先验（spatiotemporal priors，时间空间上的物理直觉）。
- 已经有人想用视频生成模型当底子（Video Policy、UVA、UWM 等），但他们要么走两阶段（先训视频、再外挂一个动作模块），要么干脆放弃用预训练视频模型从头训，丢掉了视频先验。

Cosmos Policy 的主张：用一个预训练好的视频生成模型 Cosmos-Predict2-2B（NVIDIA 出的 20 亿参数视频底模），**只做一阶段微调**，**不加任何新结构**，就能直接当机器人策略用。

## 用了什么方法（How）

- **Latent frame injection（潜帧注入）** → 类比往一串视频帧里"夹塞便条"。视频模型本来吃的是一串图像潜帧（每帧是 H×W×16 的张量），作者把机器人本体感知（关节角）、动作块（action chunk，一次出 16-50 步动作）、状态价值 V(s′) 这些非图像数据，都"伪装"成同样形状的潜帧塞进序列里。模型完全感知不到这是新模态，照常按它原来的 latent diffusion（潜空间扩散）流程一起去噪。

![Latent frame injection 总览](../papers/cosmos-policy/images/img_006.jpg)

- **一个模型同时是策略 / 世界模型 / 价值函数** → 类比一个厨师同时会做菜、会预演吃完的样子、还会给这道菜打分。每个 batch 拆成 50% 训策略 p(a, s′, V|s)、25% 训世界模型 p(s′, V|s,a)、25% 训价值 p(V|s,a,s′)，靠改"哪部分给条件、哪部分要预测"切换三种角色。
- **辅助监督（auxiliary targets）** → 让"训策略"时也顺手预测未来状态和价值。消融显示砍掉这条会掉 1.5 个点；砍掉"未来状态预测"这个辅助目标掉得最惨（67.1% → 44.4%）。
- **Best-of-N 规划（model-based planning）** → 类比下棋时先想 8 步候选、看看每步走完局面如何、挑最好的那一步落子。具体：策略采样 N 个候选动作 → 世界模型预测每个候选执行后的未来状态 → 价值函数给每个未来状态打分 → 选分数最高的执行。世界模型查 3 次、价值查 5 次取"多数均值"以抗噪。
- **双模型部署（dual deployment）** → 原始 checkpoint 当策略用；用 rollout 数据再微调一份当"规划模型"。这样规划模型评估的是原策略真实会去的状态分布。
- **噪声分布魔改** → 视频生成原本的 log-normal 噪声采样在动作生成上不够准。改成 70% log-normal + 30% uniform[1, 85]，把高噪声尾巴拉长；推理时也把 σ_min 从 0.002 抬到 4。这是经验上明显涨点的一个细节。

## 关键实验结果（What works）

- **LIBERO 平均成功率 98.5%** — 4 个子任务套件平均，刷新 SOTA，超过 OpenVLA-OFT (97.1%)、CogVLA (97.4%)。
- **RoboCasa 平均成功率 67.1%** — 24 个厨房任务，且只用 50 条人类示教，对手用的是 300-3000 条，数据效率明显更高。
- **真实 ALOHA 双臂任务平均得分 93.6%** — 对比 π0.5 (88.6%)、π0 (77.9%)、OpenVLA-OFT+ (62.0%)、Diffusion Policy (33.6%)。在"放糖入袋"这种毫米级精度任务上领先尤其大。
- **加规划后两个最难任务平均提升 12.5 分** — 证明世界模型 + 价值函数的搜索是真有用，不是装饰。代价是延迟从 0.95 秒涨到约 5 秒。

## 我读完后该懂的几个术语

- **Video foundation model（视频基础模型）** — 像 GPT 但吃视频、生成视频。这里用的是 Cosmos-Predict2-2B。类比：一个看了几亿小时短视频的"物理直觉机"。
- **Latent diffusion（潜空间扩散）** — 不直接在像素上加噪去噪，而是先用 VAE 压缩成"潜帧"再操作。类比：不在原图改像素，而是在压缩包里改字节，省算力。
- **Action chunk（动作块）** — 一次预测未来 16/32/50 步的连续动作而不是单步。类比：写字时不是写一笔停一下，而是写完一整个字再看。
- **World model（世界模型）** — 学"做了这个动作之后世界会变成什么样"。类比：脑子里的物理模拟器。
- **Value function V(s′)（价值函数）** — 估"到达这个未来状态后，最终能拿到多少奖励"。类比：下棋时给当前局面打分。
- **Best-of-N planning（N 选优规划）** — 同时想 N 套方案，挑预期最好的那个执行。类比：买菜前在心里比较 N 家店再决定去哪家。
- **VLA（vision-language-action）** — 把"看图 + 读指令 + 输出动作"打包的模型范式（OpenVLA、π0、π0.5 都是）。论文把自己定位为"不是 VLA，是 video-based policy"。

## 这篇论文的局限 / 我看出的疑点

- **推理慢**。带规划时一次出动作要约 5 秒（8 块 H100 并行），动态任务（抓飞行物、行走平衡）基本没法用。作者自己承认这是首要 future work。
- **规划要 rollout 数据才好用**。只用示教数据训出来的世界模型只见过成功路径，预测不出"抓滑了"这种失败状态，所以规划没用。需要先跑 600+ 条策略 rollout 收集失败案例后再微调。这对小实验室是一笔不便宜的成本。
- **OOD 泛化输给 π0.5**。表 3 显示在分布外条件下 π0.5 拿 92.5 反超 Cosmos Policy 的 89.3，作者归因于视频底模没在大规模机器人动作数据上预训练。换句话说，"视频先验 vs. 大规模动作监督"哪个更香还没定论。

## 与其他 12 篇的关联

- **vs. OpenVLA / π0.5（VLA 主线）**：同样做机器人模仿学习，但底模选型相反——VLA 走"图+文"，Cosmos Policy 走"视频"，押注时空先验比语义先验更适合低层控制。在 ALOHA 真机上 Cosmos Policy 平均更高，但 OOD 上 π0.5 更稳。
- **vs. Diffusion Policy**：都用 diffusion 出动作，但 Diffusion Policy 是从零训的小网络（150M 参数），这篇是从 2B 视频底模微调，结果在 LIBERO Long 上 97.6% vs 50.5%，量级差距。
- **vs. UVA / UWM / Video Policy（同样基于视频的同行）**：那几个要么两阶段、要么自己从头训视频，这篇主打"一阶段 + 用预训练底模 + 不改架构"，是该方向的简化派代表。

## 为什么值得读 / 不值得读

世界模型派进入机器人控制的代表作之一：示范了"不动结构、只换底模"也能刷 SOTA。如果你关心"视频生成模型能不能当 robotics 的 backbone"或者"world model + planning 在真机能不能落地"，这篇是必读；如果只关心 VLA 主线（语言泛化、长尾任务），可以略读对照表然后跳过细节。
