## 一句话讲什么（TL;DR）
让毫米波雷达"看穿"墙和遮挡，通过估算物体表面法向量来重建被挡住物体的 3D 形状。

## 这篇论文要解决什么问题（Why this paper）
现实里的麻烦：机器人/具身设备走进一个房间，沙发后面有没有人？柜子里放了什么东西？普通摄像头看不见被挡住的东西，这就是 NLOS（Non-Line-of-Sight，非视线场景）问题。

为什么之前的方法不够：
- 摄像头：被挡就抓瞎，只能看到光直接反射回来的表面。
- 已有 mmWave（毫米波）方法：能透过塑料/布料/薄墙拿到一些反射点，但只输出"稀疏点云"——就像在黑屋子里只摸到几个零散的点，不知道连起来是张椅子还是个箱子。
- 光学版 NLOS（Occlusion Fields 那一类）：需要超快激光 + 特殊设备，搬不进具身机器人。

## 用了什么方法（How）
> 以下方法名是基于"Surface Normal + mmWave + 3D 重建"这个组合的合理推断，不是对原文 pipeline 的精确复述。

- **mmWave 透射成像** → 类比：用 X 光看行李箱。毫米波能穿过塑料、布料、薄板，但遇到金属/水会强反射，由此拿到隐藏物体的回波信号。解决"看不见"的根本问题。
- **Surface Normal Estimation（表面法向量估计）** → 类比：摸一个看不见的物体时，每摸到一个点都同时感知"这片表面朝哪个方向"。论文核心：不只测点的位置，还测每个点表面"朝向哪边"。这一步是和"稀疏点云派"拉开差距的关键。
- **物理反射模型** → 类比：根据光打在镜子上的反射角推光源位置。毫米波回波的强度和相位跟入射角、表面材质、法向量有关，反过来就能从回波解出法向量。
- **法向量 → 几何重建** → 类比：拼一张破碎的瓷盘，光知道碎片在哪不够，还得知道每片"凹凸朝向"才能拼成完整曲面。有了密集法向量，就能用积分/拟合的方式恢复连续表面拓扑，而不是一堆点。
- **高保真 3D 输出** → 不是稀疏点云，是带表面的 mesh 或 SDF（隐式表面）级别重建，能直接喂给具身导航/抓取的下游模块。

## 我读完后该懂的几个术语
- **NLOS**（Non-Line-of-Sight，非视线）：目标被遮挡，看不见。类比：你和朋友站在 L 形走廊两端，互相看不见。
- **mmWave**（毫米波，30-300GHz）：波长毫米级的无线电波，能透过非金属薄物。类比：手机 5G 用的就是这一类，但这里波长更短、分辨率更高。
- **Surface Normal**（表面法向量）：表面每一点上"垂直朝外"的箭头方向。类比：刺猬身上每根刺指的方向。
- **Point Cloud**（点云）：一堆 3D 坐标点的集合，没有面、没有连接关系。类比：黑暗中只点亮了零散几个萤火虫。
- **3D Reconstruction**（三维重建）：从传感器数据恢复物体完整几何形状的过程。类比：根据几张照片把房子在电脑里建出来。
- **Reflectance Model**（反射模型）：描述电磁波打到表面后强度/方向如何变化的物理公式。

## 这篇论文的局限 / 我看出的疑点
> 原文未到手，以下是基于方法类型的合理质疑。

- **金属遮挡几乎必死**：mmWave 撞金属会强反射，所以"被金属盒装着的物体"基本无能为力。任务描述中强调"塑料、布料、薄墙"暗示了这个边界。
- **法向量估计受材质影响**：不同材质的反射系数不同，可能需要先验或在线校准——具身场景里物体材质多变，泛化性是个问号。
- **分辨率天花板**：mmWave 的角分辨率受天线阵列尺寸限制，重建小物体（比如杯子上的把手）可能力不从心，需读原文确认空间分辨率。

## 与其他 12 篇的关联
- 和 VLA 主线（OpenVLA / RT-2 等）几乎不重叠：那条线是"看见 + 语言 → 动作"，这条线是"看不见 → 想办法看见"。

- 与光学版 Occlusion Fields (2022) 是兄弟问题：解决同一类 NLOS，但传感器和约束完全不同——光学派靠超快激光的 time-of-flight，射频派靠穿透 + 反射模型。
