## 一句话讲什么（TL;DR）

RDT-1B 是清华团队做的 **10 亿参数双臂操作（bimanual manipulation）扩散基模（diffusion foundation model）**：把 Diffusion Policy 的"用扩散模型生成动作"思路放大到基模规模，专攻"两只机械臂协作"这个场景，先在多家机器人混合数据上预训练，再在自家双臂数据上微调，让模型能听一句话就完成倒水、叠衣服这类需要双手配合的任务。

## 这是个什么场景 — 日常类比

想象你雇了一个新厨房助手，你只能用嘴指挥他："把盘子从左手递到右手，再放进洗碗机"。

- 单臂机器人 = 这个助手只有一只手，递东西时得放下、再拿，动作是串行的
- 双臂机器人 = 助手有两只手，但两只手得"知道对方在干嘛"，不能互相打架
- RDT-1B 的目标 = 给这个双手助手装一个"足够大的脑子"，让它能听懂自然语言、看懂相机画面，然后**同时规划两只手**的下一步动作，而且这个脑子不是为某个厨房定制的，是预训练好通用底子再微调

类比里关键的两个难点：
1. 两只手的动作高度耦合（coordinated action），错一步全错
2. 双臂数据特别少 —— 现实里大多数公开数据是单臂的，等于你只看过单手厨师的视频，要训出双手厨师

## 之前的人怎么做的 — 3-5 bullet

- **Diffusion Policy（2023）**：在单臂任务上证明"用扩散模型当策略"比 MLP/Transformer 头都稳，但参数量小（百万级），任务专用，没做多任务/多机器人泛化
- **RT-1 / RT-2（Google）**：把 VLM（视觉语言模型）当作策略骨干，能跨任务，但动作是离散 token、单臂为主
- **Octo（2024）**：开源跨机器人策略，Transformer 骨干 + 扩散头，做了"多家机器人数据混合预训练"这件事，但规模仍偏小（~100M），双臂场景也不是主战场
- **ALOHA / Mobile ALOHA**：双臂硬件 + 模仿学习方案，但策略本身是任务专用的小模型，不能跨任务零样本
- 共同空白：**没人把"扩散策略 + 大规模预训练 + 双臂"三件事拼到一起**

## 这篇论文的关键想法

把"foundation model 范式"从语言/视觉搬到双臂操作上，并选**扩散模型**作为动作生成器。

核心三句话：

1. **扩散是动作分布的好建模器**：双臂动作是连续、高维（两条 7 自由度手臂 ≈ 14 维以上）、多峰（同一个任务有多种合理动作序列），扩散模型天生擅长建多峰连续分布，比离散 token 化更不损失精度
2. **scaling 也适用于策略**：把策略参数量推到 1B 级别（同期 OpenVLA 7B、π0 3B 都验证了 scaling 有效），需要 Transformer 化的扩散骨干（DiT 风格）才能撑得起来
3. **跨机器人混合预训练 + 目标本体微调**：用 46 个数据集（不同机器人形态、单臂双臂混杂）预训练通用先验，再用自家收的双臂数据精调到目标平台

## 它怎么做的（方法）— 3-4 段

**架构骨架**：DiT 风格的 Transformer 扩散模型。输入是当前观测（多路 RGB + 本体感（proprioception，机器人关节状态）+ 语言指令编码），输出是未来一段时间窗口（chunk）的双臂动作序列。扩散过程不是在像素空间，而是在**动作空间**里做去噪 —— 模型学的是"给一段噪声动作，逐步去噪还原成合理动作序列"。

**统一动作空间**：双臂、单臂、不同关节数的机器人动作维度都不一样，直接混训会冲突。论文设计了一个**统一的动作向量格式（physically interpretable unified action space）**，把不同机器人的动作填进同一组维度槽位，没用到的维度 mask 掉，让 1B 模型能在异构数据上学到共享先验。

**两段式训练**：
- 预训练：46 个多机器人数据集（OXE / RH20T / RoboSet 等的子集），任务是"给观测预测未来动作 chunk 的去噪过程"
- 微调：在自家收集的**双臂数据集（论文称 6K+ episodes 量级，具体数字需读原文）**上继续训，让模型对准目标硬件的运动学

**推理时**：给一句指令 + 当前画面 → 跑若干步扩散去噪 → 得到动作 chunk → 在机器人上执行（执行一段后再重新观测、再去噪，类似 receding horizon control）。

## 实验在做什么

笔记基于摘要，**具体数字需读原文**，已知方向：

- **真机双臂任务**：倒水、叠衣服、握手交接、家务类长程操作（long-horizon manipulation），这些都是单臂搞不定或很别扭的场景
- **零样本/少样本泛化**：测对未见过的物体、未见过的指令组合是否还能完成任务
- **scaling 实验**：可能对比 RDT-1B vs RDT-小尺寸版本，验证"参数量上去性能确实涨"
- **对比基线**：Octo、ACT（双臂模仿学习经典）、可能还有 Diffusion Policy 的双臂直接训练版
- **消融**：是否预训练（用不用 OXE）、是否扩散头（换成 MLP/MSE 头会怎样）、统一动作空间设计的必要性

## 你应该懂的几个新词 — 4-6 个

- **bimanual manipulation（双臂操作）**：两条机械臂协同完成任务，难点是动作耦合 + 数据稀缺
- **diffusion model as policy（扩散策略）**：把"图像生成"里的去噪扩散搬来当动作生成器，输入观测、输出动作分布的样本；对多峰连续动作建模特别合适
- **DiT（Diffusion Transformer）**：用 Transformer 替代 U-Net 当扩散骨干的架构，scaling 友好，RDT-1B 就是用类似思路
- **action chunk（动作块）**：一次预测未来 N 步动作而不是一步，能减少高频抖动，ACT 论文带火的概念
- **foundation model for robotics（机器人基模）**：在大量多任务多机器人数据上预训练，再微调到下游的范式，对应 LLM 里的 base model
- **unified action space（统一动作空间）**：把不同机器人形态的动作映射到同一组维度上，让混训成为可能

## 它和其他论文什么关系

- **上游**：Diffusion Policy（扩散当策略的奠基）、DiT（扩散用 Transformer）、ALOHA（双臂硬件平台）
- **同辈/竞品**：
  - Octo（2024）：开源跨机器人策略，规模更小，单臂为主
  - OpenVLA（2024）：7B 参数，VLM 路线，动作离散 token，单臂
  - π0（Physical Intelligence）：3B 流匹配（flow matching）策略，跟 RDT 思路最接近 —— 都走"大模型 + 连续动作生成 + 跨机器人预训练"，但 π0 用 flow matching 而非 diffusion
- **下游影响**：是后续国产双臂基模（如自家衍生工作）和 humanoid 全身策略的直接前作；证明"中国团队也能做基模规模的机器人策略"
- **对比角度**：和 RT-2 的关键差异 —— RT-2 把动作压成文本 token 让 VLM 输出，RDT-1B 保留动作的连续性、用扩散显式建模分布
